# Kvarnens café – exempelwebbplats

Exempelwebbplatsen som byggs i kursbokens kapitel 3–14, i färdigt skick.
Använd den som referens när du bygger din egen webbplats.

Öppna `index.html` med Live Server.

- `index.html`, `meny.html`, `kontakt.html`, `integritet.html`
- `css/style.css` – CSS-variabler, typskala, mörkt läge, Flexbox, Grid, mobilt först
- `js/main.js` – mobilmeny, "öppet nu", temaväxlare (progressiv förbättring)
- `bilder/` – optimerade bilder (WebP med JPEG-reserv), favicon och logga i SVG. I sidhuvudet ligger loggan som inline-SVG med `currentColor`, så att den följer med i mörkt läge

Bokningsformuläret pekar på en påhittad Formspree-adress och skickar inget.
